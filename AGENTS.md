# Codex instructions

- Work on one GitHub issue at a time; explain the concept and design before coding.
- Keep changes small. Use Java 21, Spring Boot and Spring AI initially.
- Add dependencies only when needed.
- Write tests and report actual test results.
- Keep README features brief and list only implemented functionality.
- Update docs/architecture.md with simple Mermaid diagrams and implementation details as features evolve.
- Never commit secrets; use environment variables.
- Require explicit approval before external write actions in the application.
- Ask before committing, pushing, merging or closing issues.
